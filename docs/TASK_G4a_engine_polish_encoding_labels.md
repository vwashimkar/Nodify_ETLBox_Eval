1. Encoding choice (one commit).
   - `IntakeSettings.Encoding` (string): "auto" (default), "utf-8", "windows-1252", "iso-8859-1", "utf-16le", "utf-16be". An unknown name gives a plain error in the result (no exception). Register `CodePagesEncodingProvider.Instance` once, in one place, safely.
