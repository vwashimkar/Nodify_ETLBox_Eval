# Task G6a for Claude Code: locate and read one CSV part (engine only)

Goal: given a file and a stored "selector", the engine finds the right CSV part in that file (the example file or a NEW file of the same instrument), checks it strictly, and streams exactly its bytes into the same ETLBox CSV code path that preview, Execute and the DLL will use. Engine and tests only: no UI, no node, no PipelineDefinition change, no DLL change, no new package. Design: reports/taskG6-design.md (accepted).
