# Task G5b for Claude Code: review tools in Intake Studio (edit, undo, save layout, lineage)

Goal: in Intake Studio the user can correct what the detector found: change the format of a part, set delimiter / header / skip lines, rename, split at a line, merge with the next part, undo, redo, go back to the detected result. The final layout is saved with the project and re-applied when the same unchanged file is opened again. Every action is written to the lineage text file. Uses the G5a engine only; no engine rule changes.
